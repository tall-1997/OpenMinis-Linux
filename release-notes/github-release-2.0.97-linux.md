# OpenMinis-Linux 2.0.97-linux 发行说明

本版收录 2.0.90 以来 81 个提交：Git 面板全面重构、子代理可视化、思考等级 ULTRA、42 项批量能力、长会话运行质量根治，以及发布前三轮机器审查全修。

## 新功能

### Git 面板全面重构

- **打开即用**：历史图谱、分支、变更列表改用原生 JGit 直读，不再依赖沙箱 shell 启动——点开面板立刻显示内容
- **Git 提交图谱**：对齐桌面端契约的图形化提交历史，分支/标签/远程装饰徽章一目了然
- **完整同步能力**：面板内直接 push / pull / 切换分支 / 查看 stash，无需再进终端
- **信息密度重构**：头卡、变更分组、提交条目、详情页、分支页全部重新设计
- **双重降级保障**：原生 JGit 与沙箱 CLI 双源互备，单源失败不再伪装成"空仓库"

### 子代理可视化

- 子代理实时进度条与详情面板重构，对齐成熟 agent 客户端形态
- 多子代理并行时收成单行卡片，dot 颜色承载运行阶段

### 思考等级 ULTRA

- 新增 ULTRA 思考等级，全链路（参数页 → 会话 → 发送）打通
- 模型参数页可手动设置思考等级上限，自定义模型参数同步补齐
- 上限变更后当前会话档位自动跟随，不再静默钳切

### Agent 能力扩展（42 项批量）

- 生成图片直接进入聊天流、代码块高亮
- 任务报告落盘、后台 job 可交互、MCP 协议面扩展、会话分支树
- 工作区/会话管理、工具 schema 补链等 42 项

### 工具与安全

- Edit / Write / MultiEdit 强制"先读后写"：未读过文件的编辑一律拒绝，杜绝盲改
- 浏览器下载以工具卡片呈现，替代分隔线
- get_cookies 语义统一：多关键词过滤不再返回空集，offload CLI 支持精确/模糊双模式

## 体验优化

### 长会话运行质量（agent 连续工作体验）

- **正文碎片根治**：模型不再在工具调用之间频繁停下输出正文打断任务推进
- **行动纪律与推理解耦**：执行纪律不再压低思考深度，工具循环更专注
- **长会话三大根因**：压缩判据、停滞检测、记忆全量注入三项修复，超长任务不再"失忆/停摆"
- 工具卡片完整参数单一结算，详情不再依赖模型自觉
- 每轮重复的 harness 提醒统一折叠，不再污染对话流
- 站立契约（人格+规则）每轮尾部重申，长对话不漂移
- work_report 陈旧快照不再每轮注入，重复不推进问题根治

### 界面细节

- Token 用量明细合并进 Token Usage 面板，单一入口
- 用量页长模型名换行完整显示，不再截断
- 冷启动进会话首帧空白大幅改善

### 记忆系统

- 召回片段跨轮去重：同一记忆不再反复"宣布"
- 每日记忆窗口恢复接入

## 问题修复

### 供应商 / OAuth

- 供应商/OAuth/Key 全模块安全硬化（1 项 P0 + 18 项 P1 + 24 项 P2）
- **OAuth 缓存断点偏移修复**：retry / resume / 重跑 / 排队续跑等 6 条路径的 cache_control 断点统一校正，Anthropic 提示词缓存真正跨轮命中
- tool_call 身份冻结：流式 delta 重派生不再覆盖真实工具 ID，工具卡片参数不再丢失
- 思考过程（CoT）翻译 9 项根因修复：语言解析、尾段补齐、失败锁存、队列不丢段等

### 人格与思考等级

- 人格/规则失效、切换供应商旧人格残留、子代理思考 OFF、i18n 英文档位——四症全修
- 思考等级停泊/恢复：低上限模型自动降级，换高档模型后原选择自动恢复且不覆盖手动新选择

### Git 面板可用性

- 浅克隆仓库历史空白、沙箱历史分隔符被剥、R8 裁剪 JGit、2s 刷新风暴——系列修复
- 外部 git 操作（终端内 commit 等）后面板自动刷新
- 沙盒内切换远程分支不再进入 detached HEAD

### 目标系统

- 旧目标不再劫持新任务；无目标写入不再凭空铸造/驱逐 Goal
- 目标完成后的回复不再丢失

### 沙箱与稳定

- 后台任务进程树豁免 kill 清扫，长跑后台 job 不再被误杀
- 供应商取消流式请求即时中断 + 终端排水有界

### 性能

- grep 扫描去 200 文件硬截：大仓库不再误报"No matches"，盲区量化可见

## 发布质量

- 发布前 P1 硬化：9 项对抗复审实锤 + 2 项崩溃级 P2
- 32 条 P2 全修：三域对抗复审逐条实证
- 复审轮 9 项实锤全修：OAuth 偏移 / 思考停泊 / 人格缓存 / detached HEAD / drain 死代码 / cookie 语义等
- R8 / CI 滚动包挡死修复（JGit 豁免、DNS 故障规避）
