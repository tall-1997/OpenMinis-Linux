# OpenMinis-Linux 2.0.82-linux 发行说明

本版收录 5 项更新：2 个新功能、1 个体验调整、多项修复与性能优化。数据库自动迁移（v23→v24），安装后首次启动会自动完成，无需手动操作。

## 新功能

### App 知识包 + 经验库（#196、#199）

Agent 操作手机 App 时不再两眼一抹黑：

- **内置 16 份常用 App 操作手册**（微信、支付宝、抖音、B站、淘宝、京东、美团、高德、QQ、微博、知乎、小红书、快手、系统设置、拨号、相机）：Agent 第一次进入这些 App 会自动读取手册，按图索骥，少走弯路
- **自己攒经验**：Agent 干完活会把"哪里有坑、入口在哪"记到本机错题本，下次再进同一个 App 先翻经验再动手；App 升级后旧经验自动标记"可能过期"
- 两个新工具 `app_guide`（查手册）/ `app_note`（记经验），Agent 可自助使用
- **经验管理移到了 记忆 页面**（原在设置页，与本页主题更搭）：查看每条经验与使用次数、一键清空

### 工具结果卡片（#196）

Agent 干完活，交的不是日志，是"成品"。工具结果现在直接渲染成卡片：

- 查设备状态/剪贴板 → 键值卡，一眼看全
- 查通讯录/短信/通话记录/应用列表、网页搜索 → 列表卡
- 生成的图片、浏览器截图 → 直接显示图片，可保存分享
- 设了闹钟/加了日历 → 日程卡
- **音量/亮度/勿扰/Wi-Fi/蓝牙/流量等变更 → 变更卡带"撤销"按钮**：点一下恢复原值，不用再让 Agent 绕一圈（10 分钟内有效）
- 写文件/改文件 → 文件卡，可直接打开

### 自定义模型增强（#195）

自定义模型接入更完整：模型信息自动补全、列表行快照缓存（更省流量）、部分操作支持宿主 su 回退。

## 修复

- **a2a 面板**：新版 WebView 上打开面板可能崩溃的问题（#198）；移动端样式改为文档启动时接线，消除桌面网格样式的首帧闪烁
- **设备工具的自动叫停恢复生效**（#197）：此前"连续失败/重复点击"的自动停止与防风控节流对设备类工具未生效，现已正常工作
- **自动化运行记录**：同一毫秒的多条记录不再导致会话页崩溃（#197）；自动清理 30 天前的历史记录
- 自动化"打开某 App"触发器此前只建不触发，现已生效（#197）

## 性能与优化（#197）

- **冷启动更快**：数据库完整性检查移出主线程（大库用户感知明显）、启动路径多项初始化延后或并行化
- **发消息更顺**：提示词组装移出主线程，流式渲染减少重复拷贝
- 无自动化规则时，系统通知不再触发任何数据库查询
- 打开会话的六次串行数据库读取改为并行；浏览器预览的 WebView 延迟到真正显示时才创建
- 内存治理：会话指纹/撤销账本随会话关闭释放、Markdown 缓存加淘汰上限
- **清理 211 个无效翻译键**（×17 语言）；合并四处重复的设置区块/空态组件/模型缓存/SSE 解析等实现，净减约 5,600 行

## 其他

- 架构门禁升级：全文件扫描全限定名引用（此前仅扫描 import 行），堵住检查盲区
- 内部质量：全量测试 4,394 项；本次修复由第三次全库架构审查（四路并行探查、约 137 项发现）驱动，报告见仓库外 `审查报告-v3.md`
