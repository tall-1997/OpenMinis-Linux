# Minis Ultra 1.36.42-linux

versionCode **95**。包名 `com.openminis.linux`。产品名仍是 Minis Ultra。

## 本版

- 设置 → 翻译增加「翻译一段文字」。页面和会话按钮走同一条路径：已保存的目标语言和翻译模型。没选模型时才用第一个已启用的模型。
- 语言栏已填好保存的语言，改了会写回同一项设置，不会再单独问一次，也不会忽略设置里的选择。
- 结果只留在这一页，不写入任何会话。
- 1.36.26 承诺的独立翻译页后来没有入口，而且写死第一个模型、语言写死中文。这一版把那条死路径删掉，接到设置里。
- 模型组上已经不用的翻译槽解析函数删掉了。旧配置里的字段仍会读写，避免加载失败。
- 角色扩展页的说明不再写高刷新率。开关在外观里，默认仍然打开。
