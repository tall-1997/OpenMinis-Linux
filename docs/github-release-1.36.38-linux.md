# Minis Ultra 1.36.38-linux

versionCode **91**。包名 `com.openminis.linux`。

## 本版

- 撤回把前台通知降到 `IMPORTANCE_MIN`、锁屏设为隐藏的做法。那样 MIUI 状态栏和灵动岛都看不到任务，体验不对。
- 通知渠道恢复为低重要性，锁屏仍可显示状态。已经装过旧版的，第一次启动会把被降级的渠道恢复一次，之后尊重系统设置里的修改。
- 经过时间改由系统计时器显示，不再把秒数写进通知正文。工具切换最多 1.5 秒刷新一次，只有文字变化时最多 30 秒刷新一次，避免灵动岛反复创建视图导致 SystemUI 内存碎片。
- 不再靠通知监听服务过滤自家通知。那拦不住系统界面，也会让本机通知查询看不到自己。

安装：允许「安装未知应用」后打开 APK。可与上游 [OpenMinis](https://github.com/OpenMinis/OpenMinis)（GPL-3.0）并排安装。debug 签名无法覆盖不同证书的已装版本，见 `docs/SIGNING.md`。
