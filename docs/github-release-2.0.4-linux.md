# Minis Ultra 2.0.4

versionCode **204**，包名 `com.openminis.linux`。

## 会话权限

- 工具闸门改为会话两档：**YOYO（全授权）** 和 **审批（部分授权）**。档位按会话落盘，打开哪个会话跟哪个走。
- YOYO：普通操作自动执行。只有格式化、清空、`rm -rf /` 这类毁灭性操作弹窗。同意执行，拒绝停。
- 审批：只读和安全查看直过。写文件、改配置、发消息、开应用、提权等一律弹窗。
- 弹窗第三项「本次会话全部允许」只放行**同类工具**。换工具还要问。毁灭性操作仍弹。
- 会话 `...` 菜单第一项改为 YOYO / 审批开关。菜单里的新建会话已去掉。
- 设置 → 权限去掉五档工具模式，只留系统权限（无障碍 / Shizuku / 存储）。

## 兼容性

- 包名、会话数据库、Provider HTTP 协议、JNI、沙箱和备份格式保持兼容。
- 可在已安装 2.0.3（versionCode 203）的同签名设备上直接覆盖升级。

## 验证

- YOYO / 审批闸门与同类工具放行单测已更新。
- 云端 release workflow 负责生成 arm64-v8a APK。
