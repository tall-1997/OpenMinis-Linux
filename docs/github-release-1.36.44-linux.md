# Minis Ultra 1.36.44-linux

versionCode **97**。包名 `com.openminis.linux`。产品名仍是 Minis Ultra。

## 本版

- 高刷新率只写一次窗口参数：选当前分辨率下刷新率最高的显示模式。不再额外写刷新率，避免部分系统先认模式、再被刷新率盖回 60Hz。
- 当前分辨率没有更快的模式时，才退到这块屏幕上最快的模式，不会为了更高数字主动降分辨率。
- 关掉高刷新率时，显示模式和刷新率偏好一起清掉，窗口回到系统默认。
- 视频结果只报告这次请求真正发出去的 `mode`。没传、供应商也没要求时，不再写成 `std`。传过的 `pro` / `std` 不会带到下一次请求。
