# Minis Ultra 1.36.36-linux

versionCode **89**。包名 `com.openminis.linux`。

## 本版

- 主页右上角菜单（终端、浏览器、浏览器设置）移到设置页，并去掉多选模式。
- 标题栏标题居中。
- 翻译改走设置 → 翻译，不再占用模型组默认槽。
- MCP 工具页可单独开关；关闭后执行层和沙箱都会拒绝调用。
- 深色模式下提问选项对比度提高。
- 一批界面文案补了中文。
- 数据库升级遇到已存在的列时跳过，不再把整库重建掉。
- 刷新模型列表不再先清空；失败的提供商会留下标记，直到下次成功。

安装：允许「安装未知应用」后打开 APK。可与官方 OpenMinis 并排安装。debug 签名无法覆盖不同证书的已装版本，见 `docs/SIGNING.md`。
