# Minis Ultra 1.36.52-linux

versionCode **105**。包名 `com.openminis.linux`。产品名仍是 Minis Ultra。

## 本版

- 点停止会立刻断开正在进行的视频 HTTP，不再等到 600 秒读超时。创建、轮询、下载和厂商媒体请求都走同一条取消链。
- 纯视频气泡生成完成后会自动打开播放器，只这一次。重新打开旧会话不会再自动播。
- 「本会话全部允许」不再跳过 `rm -rf /` 的确认。普通确认仍自动放行，致命命令和全局「全部允许」一样要弹窗。
- 子代理结束卡片只显示报告，不再把整段 Trace 写进卡片。交给父代理的工具结果仍保留 Trace。
- models.dev 目录在 gzip 打不开时可以回退到随包的明文 `models-dev-api.json`。以前代码会去开这个文件，包里却没有。
