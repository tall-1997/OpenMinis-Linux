# Minis Ultra 1.36.39-linux

versionCode **92**。包名 `com.openminis.linux`。

## 本版

- 日历、定位、通知、相册、麦克风的授权等待改成 15 秒预算。以前这些调用会按 120 秒挂住后台线程，20 秒看门狗先返回失败，用户点了允许也被丢掉。
- 超时改成跟工具自己的期限对齐：浏览器操作 100 秒，无障碍提示 75 秒，语音听写按设定时长，定位按超时上限，视频生成 18 分钟。聊天和其它短工具仍是 20 秒，避免无界面时线程越堆越多。
- 屏幕使用时间优先用前台切换事件统计。MIUI 上按天汇总的前台时长经常是 0，状态栏却有记录。没有事件时才退回系统汇总。
- 本地识图先把长边缩到 1600 像素再识别，避免相机原图把识别器撑爆。

安装：允许「安装未知应用」后打开 APK。可与上游 [OpenMinis](https://github.com/OpenMinis/OpenMinis)（GPL-3.0）并排安装。debug 签名无法覆盖不同证书的已装版本，见 `docs/SIGNING.md`。
