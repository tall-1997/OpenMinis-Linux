## 修复了什么

- **待机耗电（重点）**：修掉「开着聊天页按 Home 键，CPU 整夜不睡」的问题。根因是进入聊天页后应用会一直持有 CPU 唤醒锁，直到页面真正销毁才放——息屏、回桌面都不算。现在唤醒锁只在「有对话在跑或工具在执行」时持有，活干完立刻放。锁屏待机电流应明显回落（对应 issue #2「太耗电手机发烫」）。
- **MCP 端口冲突**：内置 MCP Server 配置的端口被别的应用占用时（例如同时装了 MCP Hub），不再启动失败，自动顺延到下一个可用端口；客户端条目自动跟随新端口，内置访问令牌也自动携带，不用手动改配置。服务器没开时快速失败并提示去设置里开启，不再傻等 30 秒超时。
- **Zen 免费通道对齐上游**：免费模型表跟随线上目录自动对齐——上游把某个免费模型下线（返回「not supported」），下次刷新自动从可选列表里摘掉，7 天内不再重试，之后上游恢复又会自动跟回来；不用等发版。本次同步摘掉了已退役的 mimo-v2.5-free。

## 优化了什么

- Zen 免费档选择器改为「目录免费档 − 实测死名单」：只信实测结果，目录里挂着但实际打不通的广告位不再凑数，避免「选了就报错」。
