# Minis Ultra 1.36.37-linux

versionCode **90**。包名 `com.openminis.linux`。

## 本版

- 设置及其一级子页不再显示多余的顶栏返回箭头，用系统返回。编辑、向导和权限页仍保留箭头。
- MCP 服务器点进去是工具二级页，可以单独开关；关掉的工具在执行层和沙箱里都会被拒绝。
- 提供商详情里刷新模型会先清掉旧列表，并清掉因此悬空的引用。刷新失败会留下标记，直到下次成功。
- 软件源页面的镜像名和地区在中文界面显示中文。

安装：允许「安装未知应用」后打开 APK。可与官方 OpenMinis 并排安装。debug 签名无法覆盖不同证书的已装版本，见 `docs/SIGNING.md`。
