# Minis Ultra 2.0.6

versionCode **206**，包名 `com.openminis.linux`。

## 前台通知与灵动岛

- 消除启动时的重复前台通知：服务只在 `onCreate` 发布一次普通占位通知，之后所有状态更新走同一发布入口。
- 通知可见状态去重：延迟回调执行前重新读取状态，状态没变就不再发通知，也不会回放旧通知。
- 通知正文不再随流式输出变化。任务计数、开始、结束、并发数变化和模式切换仍然即时更新。
- 灵动岛只在任务实际运行时请求提升；工具切换和进度变化不再重建焦点通知视图。
- 灵动岛短文本固定，耗时交给系统 Chronometer 计时，不再为秒级变化发通知。
- 任务完成或退出聊天后回到普通前台通知，不留在焦点通知里。

## 沙箱执行与内存

- 重任务按内存压力与后台 JVM 状态单通道准入，新增 `AdaptiveExecutionGate`。
- 空闲 Shell 按时长与数量上限回收，回收前检查保护中的会话与草稿。
- 工具限制新增设置项，可调空闲 Shell 数量与存活分钟数。
- 定时任务与自构建只通过追踪器发布状态，不再携带过期通知快照。

## 兼容性

- 包名、会话数据库、Provider HTTP 协议、JNI、沙箱和备份格式保持兼容。
- 可在已安装 2.0.5（versionCode 205）的同签名设备上直接覆盖升级。

## 验证

- 新增前台通知发布策略单测与执行准入单测。
- 云端 release workflow 负责生成 arm64-v8a APK。
- 灵动岛通知变更只减少通知投递，不等于修复系统侧通知泄漏；HyperOS 上仍需按同负载对比堆低点趋势验证。
