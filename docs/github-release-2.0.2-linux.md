# Minis Ultra 2.0.2

versionCode **202**，包名 `com.openminis.linux`。

## 运行时内存优化

- 构建、反编译等重任务改为全应用单通道准入。包装脚本可声明 `resource_class=heavy`，启动前检查可用内存和后台 JVM；`gradlew --stop` 与 `pkill` 仍可执行。
- 浏览器关闭、闲置淘汰和会话销毁统一释放 WebView、协程和回调。正在执行的页面操作结束后再销毁。全应用浏览器预算为 6 个标签。
- 空闲会话最多保留 3 个，估算文本预算按设备限制在 8–32MiB。草稿、运行任务、审批和下载受保护；缓存淘汰保留后台 Shell 和正式会话映射。
- Shell 预览最多 50 行 / 32Ki 字符，单消费者每 150ms 合并刷新，结束时补齐最后一次更新。
- 截图在分配位图前限制为 400 万像素、单边 4096。JPEG 只压缩一次，生成 Base64 前释放位图。
- 会话安全模式监听器在 ViewModel 清理时解绑，避免淘汰后仍被全局引用持有。

## 兼容性

- 包名、会话数据库、Provider HTTP 协议、JNI、沙箱和备份格式保持兼容。
- 可在已安装 2.0.1（versionCode 201）的同签名设备上直接覆盖升级。

## 验证

- 主工程 `compileDebugKotlin` 通过。
- Gradle 针对性单测 16/16 通过，覆盖重任务准入、日志洪流、会话淘汰和截图预算。
- 浏览器生命周期设备测试已用真实 Android 36 SDK 和主工程产物独立编译通过，尚未在反馈设备执行。
- 实际 PSS 降幅和反馈设备重启问题需在目标设备复测。
- 云端 release workflow 负责生成 arm64-v8a APK。
