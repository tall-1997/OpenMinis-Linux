# Minis Ultra 1.36.41-linux

versionCode **94**。包名 `com.openminis.linux`。产品名仍是 Minis Ultra。

## 本版

- 会话里的翻译按钮直接使用设置里已经保存的目标语言和翻译模型。点一次就翻译，不再弹出目标语言表。
- 没选到可用模型时只提示去设置里选模型，不再把语言栏再问一遍。
- 翻译按钮不再把助手正文整段左移。按钮贴在输出结束后的右下角；末行右侧有空位就嵌进去，会挡住文字才下移到刚好让开的位置。
- 1.36.35 去掉按钮 `fillMaxWidth`、1.36.36 再用右侧 40dp 留白躲图标，都是没做完的补丁。这一版按文字实际占位收尾。
- 最近三十个版本里，标题居中、会话角标、通知清空范围、定时任务落盘、模型路径改写这些已经在 1.36.40 及之前收完，这次没有再改。
