# 1.36.27-linux

versionCode **80**。安装包 `minis-ultra-com.openminis.linux.apk`。包名 `com.openminis.linux`。

相对 1.36.26-linux。这一版去掉重复设置，并修掉新功能里会误伤或卡顿的地方。

## 设置只留一处

- 工具权限模式只在「权限」页改。多智能体页不再放第二套单选，只跳过去，并显示当前模式。
- 工具上限只在上限页改。多智能体页同样只跳转。深链接 `tool-limits` 仍打开这一页。

## 新功能修正

- 显示正则按文件时间缓存。流式输出时不再每个字都读一遍磁盘。
- 选了 DuckDuckGo 时，空结果不再去打已填密钥的付费搜索。
- 博查把结果放在 `data.webPages.value`。解析会再往下走一层。
- 世界书和显示正则点按删除前要确认。
- 高刷新率只写一次窗口参数，避免模式和刷新率互相覆盖。
