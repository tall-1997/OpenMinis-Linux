# 1.36.34-linux

versionCode **87**。安装包 `minis-ultra-com.openminis.linux.apk`。包名 `com.openminis.linux`。启动器名称 **Minis Ultra**。

相对 1.36.33-linux。这一版修的是长文被键盘挡住、启动图标圆角被裁成方块、翻译按钮和翻译模型入口不清，以及自定义图片/视频路径被改写。本地已通过 `:app:compileDebugKotlin`。

## 输入和键盘

键盘弹出时，聊天输入框最高约 120dp，不再把长文顶到键盘后面。输入栏有展开按钮，打开的全屏编辑器贴在键盘上方，底部留出输入法高度。记忆管理里的长文编辑器同样避开键盘。

## 启动图标

自适应图标的前景缩进到系统安全区。圆角遮罩不再把设计好的 R 角裁成方块。旧式启动器图标四角透明，保留设计圆角。主题单色图标改回矢量剪影，不再拿彩色方图当单色层。

## 翻译

每段已经写完的助手回复，右下角有写着「翻译」的按钮，只翻译这一段，不会整段回复一起改。流式输出还没结束时不显示。

翻译用哪个模型，改到 **设置 → 模型组 → 默认设置 → 翻译**。中文界面这张卡片是中文。可以选模型组，也可以选单个已启用的模型。单个模型以 `entry:` 前缀保存，不会被当成模型组 id 去查找。

界面上去掉了「默认子代理」。它和多智能体的选择冲突。已经保存的子代理组 id 仍留在配置里，只给标题生成做回退，不再出现在这张卡片上。

## 图片和视频路径

以 `/` 开头的 `endpoint`、`image_endpoint` 按原路径请求。路径里没有 `/images/` 时，不再改写成 `/images/generations`。视频模型，或路径里带 `video` 的端点，走视频接口。

`generate_video` 可以传 `mode`（例如 `std`、`pro`）。没传、且供应商明确说 mode 必填时，补一次 `std`。这一次用过的 mode 不会带到下一次请求。

## 工具说明

`shell_execute` 的说明改为 GNU bash（`/bin/bash`），不再写成 `/bin/sh -c` 或 BusyBox ash。复合命令的安全检查没有放宽。

## 这次没改的

DuckDuckGo 搜索失败、上游额度用尽或 502，不是这个版本的产品缺陷。没有复现的问题没有臆造修复。
