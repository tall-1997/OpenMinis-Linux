## 新增了什么

- **内置 MCP Server（实验）**：手机可以直接当桌面 AI 的工具后端。PC 上执行 `adb reverse tcp:8765 tcp:8765`，Claude / Cursor 这类客户端连上就能调用手机上的 14 个工具：读写文件、列目录、定时任务、闹钟、应用查询、手机↔电脑传文件等。开关在 设置 → MCP → 「内置 MCP Server（实验）」，生成一个访问令牌即可用。
- **MCP 原生客户端**：应用内调用 MCP 服务器不再绕道终端脚本，直连、更快，断线自动重连。
- **SSH 远程执行**：新增 ssh_exec 工具，能连远程服务器跑命令、传文件；下载先落临时文件再原子替换，传输中断不会留半个坏文件。
- **本地工具插件**：插件市场新增「本地工具」区块——自己起名、写命令模板和参数，AI 就能像调内置工具一样调用它；执行照样过安全门禁，参数里带 shell 特殊字符会被拒。
- **Git 面板**：会话工作区里的 Git 仓库可以直接看改动、看历史、暂存提交，还能让 AI 写提交信息；支持嵌套仓库，文件一变自动刷新。
- **子代理后台波**：派出去的子代理可以后台跑，不堵当前对话；随时查进度、收报告，应用重启也不会丢（没收的报告会保留）。
- **语音播报**：AI 干完活可以用语音报一声，按场景可开关（默认关，设置里开）。
- **HyperOS 超级岛**：小米澎湃OS 上 AI 运行状态进超级岛和锁屏——彩色应用图标、带文字的停止按钮。
- **搜索命中跳转**：会话列表搜到内容，点结果直接跳到那条消息并高亮；冷启动后也正常。
- **代码块一键运行**：聊天里的 Python / JS / Shell / SQL 代码块带 ▶ 按钮，点一下直接跑。
- **技能录制回放**：把固定的「打开→搜索→点击」流程录成技能，AI 下次直接回放，失败自动退回手动操作。
- **免 key 搜索**：没有搜索 API key 也能搜（搜狗 → Bing → 百度 → DuckDuckGo 逐级兜底）。
- **DoH 域名解析**：系统 DNS 抽风时自动换加密 DNS 解析，请求不再卡死。
- **消息版本归档**：重新生成或截断消息前，旧版本先存进数据库归档表，有后悔药。
- **计划板 + 文件检查点**：AI 有了独立的任务计划列表（加/改/删/查），文件改动前可打检查点、随时回滚。
- **麦克风按钮开关**：输入框的麦克风可以隐藏（默认隐藏），语音模式激活时自动回来。

## 修改了什么

- **剪贴板贴图改原生**：复制图片后，长按输入框点「粘贴」，图直接进附件。原来常驻的「粘贴剪贴板图片」按钮删了——它只要剪贴板里有图就一直在，赶不走。
- **AI 过程默认折叠**：思考和工具过程默认收起，折叠条上显示总耗时，点开可看全程（设置可改回展开）。
- **更新系统重做**：下载源可以手选（GitHub 直连 / 加速镜像，自动探测哪个通）；计量网络先确认再下；下载做 sha256 完整性校验；签名不匹配会提示先卸载旧包；下载转前台服务保活，息屏不断流。
- **编辑器分工**：全屏编辑器重写成真代码编辑器（行号、语法高亮、搜索、撤销重做）；输入框的「展开编辑」则是纯文本大输入框，不再假装是 IDE。

## 优化了什么

- **提示词缓存**：每轮对话的系统提示词分片缓存，不再全量重建，更快更省 token。
- **流式续传**：回复被网络掐断会自动接着写完，不再半途而废。
- **构建与 CI**：Gradle 缓存 + 并行、PR 门禁（编译 + 测试 + 多语言字符串检查）、CI 与手机分别调对内存——CI 不再内存溢出；单元测试从 2700+ 涨到 **2852 个全绿**。

## 修复了什么

- **「禁止删除根目录」误报**：以前 `rm -rf /tmp/某目录` 这种绝对路径命令会被误拦；现在按参数精确判定。YOYO 模式下真要删根目录会弹确认而不是直接拒。顺带修好从上线就没工作过的通知栏「清理」按钮，并堵住两个真实绕过（块设备重定向写法、mkfs 误拦）。
- **数据库更稳**：归档 + 截断放进同一事务（归档失败就不删）；坏库隔离要么全做要么回滚；启动时做完整性检查，坏库自动隔离并出一次性报告，不再黑屏死循环。
- **安全修复**：文件检查点 id 路径穿越（恶意 id 逃出检查点目录）已堵；内置 MCP Server 的 HTTP 解析对中文等多字节内容不再卡死，工具调用参数加了校验和门禁。
- **模型兼容**：Gemini 思考预算上共享阶梯、不再显示实际等价的档位、不再误发预算字段；强制推理模型的思考过程可见；联网搜索结果正确性修复。
- **杂项**：偏好文件偶发写丢会自动重放重试；计划板保存失败会大声报错；检查点恢复不再误删目标文件。
